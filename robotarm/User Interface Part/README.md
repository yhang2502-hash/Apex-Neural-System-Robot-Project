# Forest Robot Final Project v3


## Web platform
Open terminal in `web_platform` folder.

1. Create `.env` from `.env.example` and fill in your Favoriot API key.
2. Run:

```powershell
npm.cmd install
npm.cmd start
```

Open browser:

```text
http://localhost:3000
```

If PowerShell blocks npm, use `npm.cmd` or open Command Prompt.
