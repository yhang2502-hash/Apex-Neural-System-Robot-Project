Restaurant Waiter-Bot Prototype

The dashboard sends commands to the backend server, then to Favoriot. ESP32 reads the latest command from Favoriot and runs the selected robot arm action. HuskyLens reads AprilTag ID1, ID2, or ID3 to choose the correct sequence.

Command mapping:
Ready Robot → READY, prepares robot and moves to HOME
Check Status → STATUS, prints robot status in Serial Monitor
Tag ID1 / Blue Sequence → BLUE robot arm sequence
Tag ID2 / Red Sequence → RED robot arm sequence
Tag ID3 / Yellow Sequence → YELLOW robot arm sequence
Manual Tag Scan → AUTO_SORT, HuskyLens detects one tag and runs the correct sequence
Read Tag Only → READ_TAG, HuskyLens reads tag ID only, no movement
Auto Tag ON → AUTO_TAG_ON, robot watches tag arrival automatically
Auto Tag OFF → AUTO_TAG_OFF, stops automatic tag watching
Safe Up → lifts the robot arm to a safer raised pose
Home Position → returns robot arm to home pose
Emergency Stop → STOP, locks robot movement for safety
